# ai-service (reserved for a later phase)

This folder is intentionally empty of code in **Phase 1**.

It is reserved for the AI capabilities of BHOOMI-DRISHTI:

- document understanding for land records (OCR + extraction)
- Retrieval Augmented Generation (RAG) over policies, circulars and research documents
- embeddings + vector search
- the AI assistant API used by the frontend

Phase 1 only creates the folder so the project layout is complete. The technology
choice (for example a Python service) and its dependencies will be decided when the
AI phase starts - no Python runtime, model server or vector database is installed yet.
